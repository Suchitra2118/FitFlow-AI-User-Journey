# FitFlow AI – User Journey Design

## Intern Details
- **Company:** SkillCraft Technology
- **Internship Domain:** UI/UX Design


## Project Name
FitFlow AI – User Journey Design

## Project Description
Designed a complete user journey for an AI-powered fitness mobile application. The project focuses on creating a smooth onboarding experience, collecting user preferences, generating a personalized fitness plan, and providing an interactive dashboard for daily fitness tracking.

## Tools
- Figma
- Iconify
- Google Fonts
